# Contact-Book-Project

Acts as another project for me to further learn code. This will only feature python and will have a smaller scope then the previous project, the Farm site. There will be no GUI as i dont wish to continue PYQT5 and dont feel confident enough in JavaScript to create a user interface. Although this is something I can implement at a later date.

DEPENDENCIES

- Pandas
- Python3

HOW TO SET UP (Linux bash)

Step 1: Open the terminal

Step 2: cd [path to the root folder]

Step 3: python3 -m venv [venv name]

Step 4: source [venv name]/bin/activate

Step 5: pip install pandas

DISCLAIMER: The program will NOT work without Pandas!!!

## How to run

**Terminal prototype** (nothing to install):

```
python3 studypilot.py
```

**Run the tests:**

```
python3 test_studypilot.py
```

**Flask website** (once built):

```
pip install flask
flask --app app run
```
