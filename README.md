# Contact-Book-Project

Acts as another project for me to further learn code. This will only feature python and will have a smaller scope then the previous project, the Farm site. There will be no GUI as i dont wish to continue PYQT5 and dont feel confident enough in JavaScript to create a user interface. Although this is something I can implement at a later date.

Dependencies: 
Python3
Pandas

## How to run

**Get the File Path**:

```
cd [The file path]
```

**Create a Virtual Environment**:

```
python3 -m venv [The Virtual Environment name]
```

**Activate the Virtual Environment:**

```
source venv [The Virtual Environment name]
```

**Install Pandas**:

```
pip install pandas
```
